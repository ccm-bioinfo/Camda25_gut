Here we provide a dataset consisting of 3752 samples originating from numerous cohorts [source] with various diseases.

The details about specific diseases and cohorts can be found in the metadata file. We provide 3 files:
- taxonomy_relative_abundance.tsv: species-level contribution to the taxonomic profile, calculated using MetaPhlAn
- pathways_relative_abundance.tsv: functional profiles of the samples, calculated using HumanN.
- metadata.tsv: contains detailed information about the samples. Not all columns need to be used in analyses. We provide additional data so that users have access to more information if needed
